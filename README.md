# 🌿 Лабиринт

2D пиксельная игра на Unity  
*Разработана студентами 1 курса в рамках учебной ознакомительной практики*

---

## 📖 Описание

«Лабиринт» — это двухмерная игра в пиксельной стилистике, в которой игроку предстоит пройти три уникальных лабиринта, собирая монеты и находя выход на следующий уровень.

Игрок управляет персонажем от третьего лица (вид сверху), перемещаясь по замкнутому пространству острова-лабиринта. Каждый уровень имеет собственную планировку, декорации и количество монет. Игра не требует обязательного сбора всех монет для прохождения, однако сохраняет лучший результат по монетам и времени, стимулируя игрока улучшать свои рекорды.

---

## 🎮 Ключевые особенности

- **Три уникальных уровня** с возрастающей сложностью лабиринта
- **Сбор монет** с анимацией пульсации и звуковым эффектом
- **Счётчик монет** в реальном времени (формат: собрано/всего)
- **Таймер прохождения** — отображается на уровне и сохраняется лучший результат
- **Сохранение рекордов** — лучший результат по монетам и времени для каждого уровня
- **Анимированный портал** для перехода между уровнями
- **Меню паузы** — возможность продолжить игру или выйти в главное меню
- **Кнопка отключения звука** — позволяет включить/выключить всю музыку и звуки
- **Кастомный анимированный курсор** — меняется при наведении на кнопки
- **Звуковое сопровождение** — фоновая музыка, звуки шагов, сбора монет, перехода

---

## 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| **W, A, S, D** или **Стрелки** | Перемещение персонажа |
| **Шестерёнка (⚙)** | Открыть меню паузы |
| **Кнопка звука (🔊/🔇)** | Включить/выключить звук |

## 🛠️ Использованные технологии

| Технология | Назначение |
|------------|------------|
| **Unity 2022 LTS** | Игровой движок |
| **C#** | Язык программирования |
| **Universal Render Pipeline (URP)** | 2D-рендеринг |
| **Tilemap** | Построение лабиринтов |
| **PlayerPrefs** | Сохранение прогресса (монеты + время) |
| **TextMeshPro** | Пользовательский интерфейс |
| **Animator** | Анимации персонажа и объектов |
| **AudioSource** | Звуковое сопровождение и музыка |
| **Git / GitHub** | Контроль версий и хостинг проекта |

## 📥 Установка и запуск

### Готовая сборка (для игроков)

1. Перейти в раздел [Releases](https://github.com/aikholz/-/releases)
2. Скачать последнюю версию (`Maze.v1.1.zip`)
