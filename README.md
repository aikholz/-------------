# 🌿 Лабиринт

2D пиксельная игра на Unity 
Разработана студентами 1 курса в рамках учебной ознакомительной практики
---
📖 Описание
«Лабиринт» - это двухмерная игра в пиксельной стилистике, в которой игроку предстоит пройти три 
уникальных лабиринта, собирая монеты и находя выход на следующий уровень. 

Игрок управляет персонажем от третьего лица (вид сверху), перемещаясь по замкнутому пространству
острова-лабиринта. Каждый уровень имеет собственную планировку, декорации и количество монет. 
Игра не требует обязательного сбора всех монет для прохождения, однако сохраняет лучший результат,
стимулируя игрока улучшать свой рекорд.

---

🎮 Ключевые особенности

- **Три уникальных уровня** с возрастающей сложностью лабиринта
- **Сбор монет** с анимацией пульсации и звуковым эффектом
- **Счётчик монет** в реальном времени (формат: собрано/всего)
- **Сохранение рекордов** - лучший результат по монетам для каждого уровня
- **Анимированный портал** для перехода между уровнями
- **Меню паузы** — возможность продолжить игру или выйти в главное меню
- **Кастомный анимированный курсор** - меняется при наведении на кнопки
- **Звуковое сопровождение** - фоновая музыка, звуки шагов, сбора монет, перехода

---

🕹️ Управление

Клавиша - Действие 
  W, A, S, D или Стрелки - Перемещение персонажа 
  Шестерёнка  - Открыть меню паузы
